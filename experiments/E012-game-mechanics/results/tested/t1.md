- **The 3 keys.** The plan's probe did not count an object script's event as testing its own slot: it kept
  `objscript:315`, `objscript:316` and `objscript:339` among the event keys. Those 3 keys are tested by no action but
  the events of their own object scripts. The plan's rule ("less each event's atoms on its own unit (its slot, ...)")
  and the amendment drop them. With them added back, the test gets the plan's 49 and 100 exactly (`tests/tested.rs`,
  `t1`). So the two counts differ from the plan's by the probe's miscount, and T follows the rule.
- `Tested::of` (through `ReadingSource::action`) equals `Tested::of_reading` (`Reading::pre_of`); T made again from
  every `record(i).pre` (the port G8 checked against PackedTask._action) equals it. Both also hold on ring(38),
  ring(33) and k = 2.
- G0 and E011's G1-G12: the component changes no existing code path (new modules, a new method `Reading::pre_of`, a
  new command; nothing in fmi-explore, fmi-play or fmi calls them), so with every E012 switch off the binaries
  behave as round 2's. tested has no switch: it is data.
