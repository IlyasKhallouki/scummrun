# 2026-10-22: E002, the cause cloud

Question: in SCUMM v5, what are all the ways a persistent fact can become true, and how large is that set
for MI1?

Prediction: none. This step counts (D3: start from the full cloud, then eliminate).

Method:
- Opcode census (`census.py`): every decompiled line, mapped by its opcode byte to ScummVM's v5 table.
- Engine table: model agents classified every o5 function and listed the engine's own trigger sites from
  the ScummVM source. Skeptics checked each group, and a critic looked for missing sites. Every row cites
  source lines. The result is a pair of fixed files in `experiments/E002-cause-cloud/results/`.
- Cloud (`cloud.py`): roots are verb handlers, room entry and exit, input scripts, cutscene and scroll
  hooks, the boot script, and engine-written variables. The call graph is read once per script context.
  Facts are every kind a script can read back or the engine checks before input.

Result (`experiments/E002-cause-cloud/report.md` has the full table):

| | Facts | Key kinds | Part I goals with a cause (exact value) | II-IV (exact) |
|---|---:|---:|---:|---:|
| Verb handlers, calls 4 deep | 2,813 | 2,353 | 97/99 (87) | 70/71 (67) |
| + calls followed to the end | 3,285 | 2,400 | 99/99 (87) | 70/71 (67) |
| All roots and kinds | 3,822 | 2,760 | 99/99 (87) | 71/71 (68) |

- Every opcode byte in MI1's 39,663 lines maps to the v5 table, and MI1 uses 86 of its 101 functions.
- Call depth converges by 8 (longest chain 9).
- The median fact has 1 writer and 6 triggers; the means are 14 and 20.
- In Part I, every goal is reachable from a verb handler, and 19 only from one.
- For the cap: 2,760 facts of the key's kinds against 170 goals.

Surprises:
- With all roots, the cloud has a cause for every goal. Whether a backward search reaches them is E001
  step 2's question.
- Five bugs in `ScriptIndex`:
  - two-flag `startScript` is not followed;
  - `Resource.loadRoom` is read as a room change;
  - writes through a variable index, or with an expression value, are dropped;
  - local calls are resolved only in the caller's room;
  - script numbers in variables are not followed.

  E001's baseline used this reader; its key does not.
- ScummVM seeds its random generator from the clock unless `random_seed` is set.

Known limits:
- 1,126 script lines with a tracked target are missed: mostly dialog lines being created (573), actors
  held in variables and cursor lines.
- The engine table lists side effects the extractor does not model (pickupObject's class and state,
  loadRoom's actor resets).
- 14 scripts are reached from no root.
- The index fan-out and the grow-only room set over-approximate. They are the first candidates for
  elimination.

Deviation: seven reading rules were added during the run, each to close a gap on a Part I goal or a
parsing error. Held-out results were read as totals only.

Decision: D4, no size cap. The next step searches the full cloud for a path from start to end.
