## shared_runs

On k = 2, the five `dialog_line(·)[202@85]` jobs run alone give the same records and counters with the switch on and
off, with one run made and four taken (`tests/shared_runs.rs`). In the k = 1 reading 6 runs were kept and taken 12
times; in k = 2, 30 kept, 78 taken, and 74 not kept because the run read a dialog verb.

The gain on the check scopes is below E004's 5%: reading CPU 222.2 s against 217.1 s on k = 1 (2.3%) and 423.5 s
against 413.7 s on k = 2 (2.3%), off as the lower of two runs, on from one run. The two off runs differ by 1.0% and
2.8%. So by E004's keep rule the switch is not kept as a size step; it stays off by default.

In Part I's reading the switch does not apply where the plan expected it. The run of `dialog_line(120)[202@85]`
reads a dialog verb fact past its own click (`not shared, it reads a dialog verb`), so each of the five jobs runs
alone. Which read it is was not traced. The run changes the room (global 114's `loadRoom(49)`), and the code that
change reaches holds readers of every dialog verb: global 17, which room 85's exit starts, gives verbs 120 to 128
`VerbOps(New)`, and the machine reads a verb before `VerbOps` writes it. So the five runs' equal counters come from
code that treats the verbs alike, not from code that leaves them unread. On k = 2 the run leaves the scope at that
room change and is shared. The plan's prediction for round 4 (3,590 s to about 720 s) does not hold.

## What the trace picks among A6's options

- **(a) first.** The `[202@85]` dialog family is 99% of round 4's job seconds and 17% of round 5's so far. On k = 2,
  h² over (var:32, room) pairs finds (202, 85) unreachable, so the family could go exactly. Part I's own check needs
  a finished reading, or (a) inside the reader, where the pairs grow with the rounds as `--reach`'s values do.
- **(d) next.** Most of the rest of round 5 is 96 sentence jobs (4,061 s) whose preconditions name no var:32 (on
  k = 2's reading they name room 85, or no room), so (a) on (var:32, room) leaves them. Their cost is one shared suffix,
  the room change into room 49 and room 49's code, which is what a store keyed on the suffix's point, live state and
  read facts would share.
- **(c)** would cut the 962 s of reruns from held branches, which (a) removes with the family.
- Weighting each long run's seconds by its fork counts, round 4's went 2,843 s to forks on non-fact tests against
  908 s to forks on reads, and round 5's 1,944 s against 1,796 s.
