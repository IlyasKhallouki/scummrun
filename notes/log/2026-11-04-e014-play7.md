# 2026-11-04: E014, the interactive demo from the boot with the model working after the opening

Amendment (6) made the reading after the demo's opening take about 20 s instead of more than 15 minutes. This run asked
what the explorer does once the model is there. Two general fixes went in first (amendment (7) of
`experiments/E014-fate-demo/plan.md`):

- **Stagnation after a sweep** (`FMI_STAG_CELLS=1`). The stop fires only once every selectable cell has had a try since
  the last new atom. play4 had stopped with 6 of its 27 cells never tried. On play4's own files the rule now says "not
  stagnant".
- **An input the bridge refuses is one refused trial,** not the end of the try. The input that had ended a try in play4
  was a click on an actor standing left of the screen.

Monkey Island's checks hold with both on. The run was on the cloud VM (10 workers), from the boot, every switch on.

## The result

The run stopped by its falsifier at 80 tries, after 7.7 minutes, without reaching the game's end.

- **Entries:** 175, all in room 49, the room the game opens in. All 174 past the root replay from boot with 0
  differences.
- **Progress:** 62 new tested atoms, against 40 in play4. The deepest chain has 10 inputs. The furthest entry is at
  frame 12,272, though most of those frames are waiting after the last input at frame 1,472.
- **Objects:** no owner and no state changed. One class bit of one object did.
- **Still finding:** the last two tries gave new atoms, so the falsifier stopped a run that had not stalled.
- **Cost:** the VM was up 0.39 h, $0.60.

## What the model does now

No reading reached the 300 s bound; the 41 fresh readings took 0.5-50 s. The model plans from the states after the
opening, and the engine refutes the plans:

| class | share of the try wall |
|---|---:|
| effect mismatch | 38% |
| interface, no yield | 23% |
| model-blind | 14% |
| productive | 14% |
| no plan | 10% |

- **Effect mismatch.** Plans for one sentence (verb 10 on object 592) ran, and the write the record predicted was not
  in the engine's run. This grew to 75% of the last 20 tries' seconds. Amendment (6)'s widened records are more
  general by design; whether they cause this is not measured yet.
- **Model-blind.** 16 tries started from states holding a script position the reading never reaches.
- **No plan.** 7 tries were for a target the planner proved unreachable.
- **A planner error.** One refinement left a task without the target's fact.

## Two smaller findings

- **Actors off the screen.** The offer gives an actor the point (x less the camera), with no check that the point is
  on the screen. 86 trials in 4 tries clicked an actor left of the screen. They are now refused trials (17 s in all),
  but the point should not be offered.
- **The demo is cheap now.** Model tries took 52 s on average on the VM, free tries 26 s. Eighty tries is a few minutes
  of a 30-core machine, so the falsifier, not the time, set the run's length.
